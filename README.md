# qirtas_backend

Backend TypeScript + Express + PostgreSQL + Drizzle ORM لتطبيق Flutter بـ `../qirtas_app`.

**ابدأ من هنا**: [CLAUDE.md](CLAUDE.md) — الفهرس الكامل للتوثيق والقواعد.

سريع:

```bash
npm install
cp .env.example .env   # اضبط DATABASE_URL
npm run db:generate && npm run db:migrate
npm run dev
```
